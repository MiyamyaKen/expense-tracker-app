# 记账App

一个简洁实用的个人记账应用，帮助你轻松管理日常收支。

## 功能特点

### 📊 统计概览
- **总余额**：实时显示当前总余额
- **总收入**：统计所有收入记录
- **总支出**：统计所有支出记录（包含固定支出）
- **固定支出**：独立显示每月固定支出总额

### 💰 收支管理
- **添加记录**：快速添加收入或支出记录
- **编辑记录**：点击记录可以修改金额、分类、日期和备注
- **删除记录**：轻松删除不需要的记录
- **分类管理**：支持12种分类
  - 支出：餐饮、交通、购物、娱乐、医疗、教育、住房、旅游、信用卡还款、其他
  - 收入：工资、投资、其他

### 🔍 筛选功能
- **类型筛选**：查看全部/收入/支出记录
- **分类筛选**：按具体分类查看记录
- **月份筛选**：按月份查看历史记录
- **关键词搜索**：在备注中搜索关键词

### 📅 月份分组
- 记录按月份自动分组显示
- 每月显示该月的收入、支出和结余统计
- 清晰的时间线展示

### 🔄 固定支出管理
- 添加每月固定支出项目（如房租、水电费等）
- 固定支出独立统计，但计入总支出
- 可以编辑和删除固定支出项目

### 💾 数据持久化
- 使用浏览器本地存储（LocalStorage）
- 数据自动保存，刷新页面不丢失
- 支持导出和备份（计划中）

## 技术栈

- **HTML5**：语义化标签
- **CSS3**：现代化样式，响应式设计
- **JavaScript (ES6+)**：原生JavaScript，无依赖
- **LocalStorage**：本地数据存储

## 使用方法

1. 打开 `expense-tracker.html` 文件
2. 开始添加你的收支记录
3. 使用筛选功能查看不同维度的数据
4. 管理你的固定支出项目
